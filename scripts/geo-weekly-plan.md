# GEO + SEO Optimization Plan - Updated 2026-07-13

## GEO (Generative Engine Optimization) Strategy

GEO targets AI-powered search engines: ChatGPT, Google AI Overviews, Perplexity, Bing Copilot, etc.

### Core GEO Principles Applied:
1. **Structured Data Excellence** - Rich Schema.org markup (WebSite, Organization, LocalBusiness, Product, Article, FAQPage, Service, HowTo)
2. **AI-Extractable Content** - KeyTakeaways, QuickStats, Definition Blocks, Comparison Tables
3. **Entity Clarity** - Clear named entities with DefinedTerm, Person (Author), Organization schemas
4. **Citation-Ready Format** - Bullet points, numbered lists, clear heading hierarchies
5. **Q&A Optimization** - FAQPage schema on all applicable pages, question-based H2/H3 headings
6. **Content Freshness** - dateModified on all articles
